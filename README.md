# 🤖 AI Chatbot

A simple AI chatbot built with Python, Streamlit, and the OpenAI API. The chatbot allows users to enter messages and receive AI-generated responses through a web-based interface.

## 📌 Project Overview

This project demonstrates how to build a basic AI-powered chatbot that:

- Accepts user messages
- Sends messages to an AI model through the OpenAI API
- Displays AI-generated responses
- Maintains conversation history during the session
- Provides a simple and user-friendly web interface
- Handles API errors

## 🛠️ Technologies Used

- **Python**
- **Streamlit** – for the web interface
- **OpenAI API** – for AI-generated responses
- **python-dotenv** – for loading the API key securely
- **Git & GitHub** – for version control and project submission
